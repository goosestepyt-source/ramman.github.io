Privacy Policy

Ramman Analytics · Last updated 7 November 2026

Ramman Analytics is a personal reporting tool used only by the owner of the Ramman YouTube channel. This policy explains how it accesses and handles Google user data.

What data is accessed

With the channel owner's permission, the tool uses read-only access to the YouTube Data API and YouTube Analytics API to read the owner's own channel information, video details and channel analytics, including views, watch time, subscribers, traffic sources and estimated revenue.

How the data is used

The data is used only to generate weekly performance reports for the channel owner. It is not used for advertising, profiling or any other purpose.

Storage

All data and reports are stored locally on the channel owner's own computer. Nothing is uploaded to a server operated by this tool.

Sharing

Google user data is not sold, shared with or transferred to any third party.

Google API Services User Data Policy

Ramman Analytics' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions. Locally stored data can be deleted by removing the tool's folder.

Contact

Questions about this policy can be sent through the contact details on the Ramman YouTube channel.
