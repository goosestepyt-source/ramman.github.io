Ramman Analytics

A private reporting tool for the Ramman YouTube channel.

Ramman Analytics is a personal tool used by the owner of the Ramman YouTube channel (@IAmRamman). It connects to the YouTube Analytics API and YouTube Data API with read-only access to produce a weekly performance report covering views, watch time, subscribers, revenue, traffic sources and per-video results.

The tool is not a public service. It only accesses data for the channel owner's own account, and all reports are generated and stored on the owner's own computer.

Read the Privacy Policy for details on how YouTube data is accessed and handled.
